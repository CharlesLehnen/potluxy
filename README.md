# Potluxy™

Potluxy is a simple, intuitive web application designed for organizing potlucks or any events where multiple participants sign up to bring various items. Inspired by the straightforward interface of when2meet.com, Potluxy is built for ease of use with no sign-ups required. Optional event-specific passwords allow users to edit their entries later if needed.

## How It Works

1. **Create an Event**: Event organizers can create an event with a title, date, and a list of items needed for the potluck.
2. **Sign Up for Items**: Participants can view the list of items and sign up to bring specific ones without needing to create an account.
3. **View the Event**: All participants can view the updated list of items and who's bringing what, ensuring no duplicates and that everything needed is accounted for.
4. **Edit Entries**: Optionally, event creators or participants can set a password during sign-up, allowing them to log back into the event and change their entries later.
